## این چیست؟

یک دستیار ویراستاری فارسی برای هوش مصنوعی. ۱۵۷۷ نکتهٔ ویراستاری را در خودش دارد؛
از نیم‌فاصله و ویرگول تا جمله‌بندی، واژه‌گزینی و لحن. به هر برنامهٔ هوش مصنوعی وصل می‌شود؛ مثل Claude Desktop، Cursor و n8n.

کافی است متن را بدهی. اول خودش متن را می‌خواند و ایرادهایش را پیدا می‌کند؛
بعد از میان نکته‌ها، برای همان ایرادها یک چک‌لیست مخصوص می‌سازد.
هوش مصنوعی با همان چک‌لیست متن را ویراستاری می‌کند، یک بازبینِ دیگر آن را کنترل می‌کند،
و در آخر، خودش یک بررسی نهایی هم می‌کند.
خروجی: متنِ تمیز، به‌علاوهٔ گزارشِ این‌که چه چیزهایی درست شد.

## چه چیزهایی را درست می‌کند؟

- حروف عربیِ قاطی‌شده در متن (ي، ك)
- نشانه‌گذاری لاتین (ویرگول و علامت سؤال فرنگی و...)
- نیم‌فاصله‌های جاافتاده («می شود» به‌جای «می‌شود»)
- جمله‌های خیلی بلند و خسته‌کننده
- حشو اداری («می‌باشد»، «لذا»، «گردید»...)
- واژه‌های نامناسب و لحنِ ناهماهنگ

## چطور کار می‌کند؟ (ساده)

۱. **تمیزکاری اولیه**: ایرادهای ساده و مشخص (مثل حروف عربی) خودکار درست می‌شوند.
۲. **معاینه**: متن بررسی می‌شود؛ مثلاً اگر جملهٔ بلند دارد، نکته‌های «جملهٔ بلند» آورده می‌شود.
۳. **ویراستاری**: هوش مصنوعی با چک‌لیست، متن را ویراستاری می‌کند.
۴. **بازبینی**: یک بازبینِ دیگر، تک‌تک بندهای چک‌لیست را روی متن کنترل می‌کند؛
 اگر چیزی جا مانده باشد، برمی‌گردد برای اصلاح (تا ۴ بار).
۵. **کنترل نهایی**: آخرش هم خودش بررسی می‌کند که چیزی جا نمانده باشد؛
 اگر موردی نیاز به نظر انسان داشته باشد، در گزارش اعلام می‌شود.

## شروع سریع

بدون داکر، با pip:

```bash
pip install git+https://github.com/masoud-1378/persian-writing-mcp.git
obper-mcp
```

یا با داکر (از ریشهٔ ریپو):

```bash
docker build -t persian-writing-mcp .
docker run -p 8060:8060 -e OP_MCP_API_KEY='یک-کلید-طولانی-و-تصادفی' persian-writing-mcp
```

به پایتون ۳.۱۰ یا بالاتر نیاز دارید.

## وصل شدن به برنامه‌ها

- **Claude Desktop و Cursor**: همین دستور `obper-mcp` را به‌عنوان ابزار اضافه کنید؛
 بعد در هر گفت‌وگو می‌توانید بخواهید متنتان را ویراستاری کند.
- **n8n**: دو ورک‌فلوی آمادهٔ ایمپورت در پوشهٔ [examples](examples) هست
 (یکی ساده برای کار روزمره، یکی کامل با همهٔ مرحله‌های بالا)؛ راهنما: [docs/n8n.md](docs/n8n.md).
- **کد خودتان**: راهنمای کامل الگو با نمونه‌کد در [docs/deep-edit.md](docs/deep-edit.md) است.

اگر برنامه‌تان روی شبکه است، سرور را این‌طور اجرا کنید:

```bash
obper-mcp --transport streamable-http --port 8060 --api-key SECRET
```

## برای توسعه‌دهندگان

۱۱ ابزار دارد؛ مهم‌ترین‌ها:

| ابزار | چه می‌کند |
|---|---|
| `smart_rules` | متن را می‌خواند و برای ایرادهایش چک‌لیست مخصوص می‌سازد |
| `mechanical_pass` | تمیزکاری خودکارِ بدونِ حدس + کنترل نهایی |
| `verify_regression` | چک می‌کند ایرادهای پیدا شده واقعاً حل شده‌اند یا نه |
| `diff_report` | فهرست دقیق همهٔ تغییرها، برای حسابرسی |
| `rule_pack` | چک‌لیست کوتاه برای یک نوع متن (مثلاً گزارش رسمی) |
| `search` / `ruling` / `read_note` | جست‌وجو و خواندن نکته‌ها |

## مشارکت

ایده و پول‌ریکوئست (درخواست ادغام) خوش می‌آید. پیش از پوش، تست‌ها را اجرا کنید:

```bash
python tests/test_smoke.py
python tests/test_golden.py
```
