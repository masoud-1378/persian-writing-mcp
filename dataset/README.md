# دیتاست ویراستاری فارسی

بذر دیتای فاین‌تیون رفتار ویراستار. هر سطر یک JSON با این شکل است:

```json
{"dirty": "متن خراب", "clean": "متن تمیز", "corruptions": ["latin_punct", "zwnj_drop"], "source": "vault-note", "task_type": "متن عمومی"}
```

## سه سطح دیتا

۱. **مصنوعی** (`seed.jsonl` همین‌جاست، ۵۰۰ جفت): متن تمیز واقعی × خراب‌سازی مهندسی‌شده. طرف تمیز ۱۰۰٪ انسانی و درست است؛ خرابی‌ها دقیقاً همان خانواده‌هایی‌اند که خط لوله برای درست کردنشان ساخته شده، پس همهٔ جفت‌ها «یادگرفتنی»‌اند. ابزار ساخت: `tools/build_dataset.py`.

۲. **ارگانیک** (لاگ خط لوله): هر اجرای واقعی که هر سه دروازه را رد کند، یک جفت ثبت می‌کند: ورودی، خروجی، قواعد اعمال‌شده، رأی بازبین. فرمت JSONL در `dataset/runs/`. کند ولی خطاهای واقعیِ دنیای واقعی را دارد.

۳. **طلایی انسانی**: اجراهایی که پرچم `needs_human_review` خوردند و انسان تأییدشان کرد. کم‌حجم، بالاترین وزن در آموزش.

## بزرگ کردنش

- متن تمیز بیشتر: دامپ ویکی‌پدیای فارسی (CC BY-SA، با ذکر منبع)، کتاب‌های آزاد.
- خرابی بیشتر: هر نشانهٔ تازه‌ای که به `diagnose` اضافه شد، یک تابع خراب‌سازی هم در `build_dataset.py` می‌گیرد.
- با همین ابزار، ۵۰۰ هزار جفت هم می‌شود ساخت؛ فقط متن تمیز می‌خواهد.

## نکتهٔ لایسنس

بذر فعلی از یادداشت‌های خودِ والت آمده که مال خودمان است. اگر از ویکی‌پدیا متن برداشتید، CC BY-SA را با ذکر منبع رعایت کنید.
