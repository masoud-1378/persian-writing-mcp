# ویراستاری عمیق فارسی: الگوی عمومی

این الگو به هیچ پلتفرمی قفل نیست. MCP فقط «قاعده» می‌دهد
(ابزار `deep_rules`: یک چک‌لیست ~۴۰ قاعده‌ای از نوع متن + پنج بُعد ثابتِ
نیم‌فاصله، نشانه‌گذاری، جمله، واژه و لحن) و **هر ایجنتی** حلقهٔ ویراستاری را
اجرا می‌کند: Claude Desktop، Cursor، ChatGPT، n8n، یا کد خودتان.

## ایده در پنج قدم

۱. یک فراخوانی `deep_rules` با نوع متن → چک‌لیست کامل.
۲. **ویراستاری:** متن با تک‌تک بندهای چک‌لیست ویراسته می‌شود.
۳. **بازبینی:** متن ویراسته بندبه‌بند با همان چک‌لیست سنجیده می‌شود؛
   خروجی فقط JSON است: `{"issues": [...], "clean": true/false}`.
۴. اگر تمیز نبود، فقط ایرادهای گزارش‌شده اصلاح می‌شود
   (بقیهٔ متن دست نمی‌خورد) و قدم ۳ تکرار می‌شود؛ سقف ۴ پاس.
۵. **خوانش آخر:** متن با چشم خوانندهٔ نهایی خوانده می‌شود؛
   ریتم، تکرار، غلط تایپی و گوش بومی.

## پرامپت آماده (کپی و استفاده در هر ایجنت)

```
تو ویراستار ارشد زبان فارسی هستی؛ مسلط به رسم‌الخط و نیم‌فاصله،
نشانه‌گذاری فارسی، دستور زبان، جمله‌بندی، واژه‌گزینی، سبک و لحن.
نشانه‌گذاری فقط فارسی (، ؟ ؛ «»)؛ خط تیرهٔ فرنگی ممنوع؛ رجیستر یکدست.

متن زیر را در چند پاس صیقل بده:

پاس ۱: با ابزار deep_rules چک‌لیست ویراستاری را برای نوع متن «{نوع متن}»
بگیر و متن را سطر به سطر با تک‌تک بندهایش ویراستاری کن.

پاس‌های بعد: خودت بازبین سخت‌گیر باش: متن ویراسته را بندبه‌بند با همان
چک‌لیست بسنج و ایرادهای باقی‌مانده را فهرست کن. فقط همان ایرادها را اصلاح کن.
تا وقتی ایرادی هست ادامه بده (حداکثر ۴ پاس).

خوانش آخر: متن را مثل خوانندهٔ نهایی بخوان؛ اگر جایی گیر کردی، همان‌جا را
روان کن. در پایان فقط متن نهایی را برگردان، بدون توضیح اضافه.

متن:
{متن}
```

## با Claude Desktop یا Cursor

۱. این ریپو را به‌عنوان MCP اضافه کنید (حالت stdio):
   `obper-mcp`
۲. پرامپت بالا را با متن و نوع متن بدهید.
۳. ایجنت خودش `deep_rules` را صدا می‌زند و حلقه را اجرا می‌کند.

## با API یا کد خودتان

```python
rules = mcp.call("deep_rules", {"task_type": "گزارش رسمی"})
checklist = rules["checklist"]          # رشتهٔ آمادهٔ الصاق به پرامپت
for _ in range(4):
    edited = llm.edit(text, checklist)          # پاس ویراستاری
    review = llm.review(edited, checklist)      # بازبینی → JSON
    if review["clean"]:
        break
    text = llm.fix(edited, review["issues"])    # اصلاح فقط ایرادها
final = llm.final_read(text)                    # خوانش آخر
```
