# ویراستاری عمیق فارسی: معماری حرفه‌ای

## یک حرف رک

۱۰۰٪ مطلق را هیچ سیستمی نمی‌دهد؛ نه AI، نه انسان. چیزی که می‌شود مهندسی کرد
این است که هیچ ایرادی **بی‌سروصدا** رد نشود، هر تغییری **ثبت** شود، و کیفیت
**اندازه‌گیری** شود. این سند همان معماری است؛ مثل یک تحریریهٔ واقعی.

## نقش‌ها (جدا از هم)

| نقش | کیست | به چه دسترسی دارد |
|---|---|---|
| پذیرش | الگوریتم قطعی | `mechanical_pass` |
| معاینه‌گر | الگوریتم قطعی | `smart_rules` (بخش diagnose) |
| ویراستار | مدل زبانی سریع | چک‌لیست |
| نمونه‌خوانِ مستقل | مدل قوی‌تر و جدا + ابزارهای والت | `search`/`ruling`/`read_note`/`map_vault` + چک‌لیست |
| دروازه‌بان | الگوریتم قطعی | `mechanical_pass`، `verify_regression`، `diff_report` |

قانون طلایی: **سازنده و داور یکی نیستند.** ویراستار با مدل سریع کار می‌کند؛
نمونه‌خوان با قوی‌ترین مدل، مستقل از ویراستار، و با کلید کتابخانه (ابزارهای والت)
در دست. شک را خودش در والت راستی‌آزمایی می‌کند.

## هفت قدم

۰. **پالایش مکانیکی** (`mechanical_pass`): حروف عربی، نشانه‌گذاری لاتین،
   «می» جدا از فعل، فاصله‌ها؛ قطعی و تکرارپذیر.
۱. **معاینه** (`smart_rules`): ۱۶ نشانه بررسی می‌شود و برای ایرادهای واقعیِ
   همان متن، قاعده آورده می‌شود (هر قاعده با دلیل انتخاب).
۲. **ویراستاری** با چک‌لیست.
۳. **نمونه‌خوانی مستقل**: قاعده‌به‌قاعده، برای هر بند جداگانه رأی؛
   هر شک با ابزارهای والت راستی‌آزمایی می‌شود. خروجی فقط JSON.
۴. **تکرار** قدم ۲ و ۳ تا تمیز شدن (سقف ۴ پاس)؛ فقط ایرادها اصلاح می‌شود.
۵. **خوانش آخر** با چشم خوانندهٔ نهایی.
۶. **دروازه‌ها** (همه قطعی، بدون مدل):
   - مکانیکی: چیزی از دستهٔ مکانیکی نمانده باشد؛
   - رگرسیون (`verify_regression`): هر سیگنالی که در ورودی بود، در خروجی حل شده باشد؛
   - دفتر تغییرات (`diff_report`): فهرست قطعیِ هر تکه‌ای که عوض شد، برای ممیزی انسانی.

اگر دروازه‌ای نگیرد، خروجی با پرچم `needs_human_review: true` برمی‌گردد؛
نه ردِ بی‌سروصدا، نه توقفِ بی‌خبر.

## اندازه‌گیری کیفیت

کیفیت حرف نیست، عدد است. در `tests/golden_cases.json` دوازده متنِ عمداً خراب
هست با ایرادهای معلوم؛ `tests/test_golden.py` روی هر کدام چک می‌کند:
نشانه‌ها پیدا شدند؟ لایهٔ مکانیکی تمیز کرد؟ چک‌لیست معنادار آمد؟
دروازه روی متنِ اصلاح‌نشده **رد** می‌کند؟ این تست‌ها در CI روی هر پوش اجرا می‌شوند.

## پرامپت آماده (کپی و استفاده در هر ایجنت)

```
تو ویراستار ارشد زبان فارسی هستی؛ مسلط به رسم‌الخط و نیم‌فاصله،
نشانه‌گذاری فارسی، دستور زبان، جمله‌بندی، واژه‌گزینی، سبک و لحن.
نشانه‌گذاری فقط فارسی (، ؟ ؛ «»)؛ خط تیرهٔ فرنگی ممنوع؛ رجیستر یکدست.

متن زیر را در چند پاس صیقل بده:

قدم صفر: با ابزار mechanical_pass پالایش مکانیکی کن.

پاس ۱: با ابزار smart_rules چک‌لیست ویراستاری را برای این متن و نوع متن «{نوع متن}»
بگیر و متن را سطر به سطر با تک‌تک بندهایش ویراستاری کن. به ستون «چرا»ی هر قاعده توجه کن.

پاس‌های بعد: نقش نمونه‌خوانِ مستقل را بگیر: به ابزارهای والت دسترسی داری
(search، ruling، read_note، map_vault). متن ویراسته را قاعده‌به‌قاعده بسنج؛
برای هر بند جداگانه رأی بده و هیچ بندی را رد نکن. هر شکی را اول با ابزارها
در والت راستی‌آزمایی کن. ایرادهای باقی‌مانده را فهرست کن و فقط همان‌ها را اصلاح کن.
تا وقتی ایرادی هست ادامه بده (حداکثر ۴ پاس).

خوانش آخر: متن را مثل خوانندهٔ نهایی بخوان؛ اگر جایی گیر کردی، همان‌جا را روان کن.

دروازه: با verify_regression ورودی و خروجی را مقایسه کن؛ اگر سیگنالی حل‌نشده ماند،
اعلام کن. در پایان فقط متن نهایی را برگردان، بدون توضیح اضافه.

متن:
{متن}
```

## با Claude Desktop یا Cursor

۱. این ریپو را به‌عنوان MCP اضافه کنید (`obper-mcp`، حالت stdio).
۲. پرامپت بالا را با متن و نوع متن بدهید؛ برای نقش نمونه‌خوان از قوی‌ترین مدل استفاده کنید.

## با API یا کد خودتان

```python
text = mcp.call("mechanical_pass", {"text": text})["fixed"]
rules = mcp.call("smart_rules", {"text": text, "task_type": "گزارش رسمی"})
checklist = rules["checklist"]
for _ in range(4):
    edited = llm_edit(text, checklist)            # ویراستار (مدل سریع)
    review = llm_review(edited, checklist)       # نمونه‌خوان مستقل (قوی‌ترین مدل + ابزار والت)
    if review["clean"]:
        break
    text = llm_fix(edited, review["issues"])
final = llm_final_read(text)
gate_m = mcp.call("mechanical_pass", {"text": final})
gate_r = mcp.call("verify_regression", {"before_text": text0, "after_text": final})
ledger = mcp.call("diff_report", {"before_text": text0, "after_text": final})
needs_human = not gate_m["clean"] or not gate_r["pass"]
```
