# Persian Writer Second Brain Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ساخت یک مغز دوم منبع‌محور، شبکه‌ای و ریزدانه برای نویسندگی فارسی با تمرکز بر نثر کاربردی معاصر و پوشش مستقل نویسندگی ادبی.

**Architecture:** مجموعه به حوزه‌ها، زیرحوزه‌ها و یادداشت‌های اتمی تقسیم می‌شود. یادداشت‌های نقشهٔ محتوا دو مسیر «یادگیری» و «مراجعه هنگام نوشتن» را فراهم می‌کنند؛ دفتر منابع، دفتر ادعاها و ماتریس شکاف‌ها امکان ردیابی پژوهش و اختلاف منابع را می‌دهند.

**Tech Stack:** Obsidian، Markdown، YAML properties، Wikilink، منابع وب و دانشگاهی، PowerShell و ripgrep برای کنترل ساختاری.

**Spec:** `D:\Notes\نویسندگی و تولید محتوا\00-راهنمای استفاده و نقشه راه\00-طرح معماری مغز دوم نویسنده فارسی.md`

## Global Constraints

- زبان اصلی همهٔ یادداشت‌های آموزشی فارسی معیار معاصر و روان است.
- تمرکز اصلی بر نثر کاربردی معاصر است؛ نویسندگی خلاق، ادبیات، شعر و بلاغت نیز مستقل و جامع پوشش داده می‌شوند.
- هر یادداشت فقط یک پرسش، قاعده، تصمیم یا ابزار مشخص را پوشش می‌دهد.
- هیچ موضوعی با توصیه‌های کلی بسته نمی‌شود؛ قاعده، مرز کاربرد، استثنا، اختلاف، مثال، خطا و منبع باید بررسی شوند.
- «الزام رسمی»، «صورت معیار»، «توصیهٔ ویراستاری»، «کاربرد رایج» و «انتخاب سبکی» از هم تفکیک می‌شوند.
- منبع اولیه و رسمی بر منبع ثانویه مقدم است؛ ادعاهای مهم و اختلافی با منبع مستقل دیگری مقابله می‌شوند.
- هر مثال نادرست باید توضیح خطا و صورت اصلاح‌شده داشته باشد.
- یادداشت فاقد شواهد کافی با وضعیت `verified` منتشر نمی‌شود.
- هیچ تعداد ثابتی برای یادداشت‌ها تعیین نمی‌شود؛ پایان هر حوزه تابع پوشش پرسش‌های اتمی و ثبت صریح شکاف‌هاست.
- Vault مخزن Git نیست؛ در نتیجه مراحل commit اجرا نمی‌شوند و نسخه‌های مهم با نام و تاریخ در یادداشت‌های وضعیت ثبت می‌شوند.
