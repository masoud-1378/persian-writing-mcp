## نقشهٔ خانواده‌ها (زنجیرهٔ یادگیری)

هر خانواده یک زنجیرهٔ پیش‌نیاز به پس‌نیاز است؛ از سرِ زنجیره شروع کن. میان خانواده‌ها هم پیوند مرزی برقرار است.

**درگاه حوزه:** [[سطوح تحلیل زبان]] ← آغاز یادگیری این حوزه

1. [[سطوح تحلیل زبان]] → [[واج در فارسی معیار]] → [[رابطهٔ واج و نویسه]] → [[تکواژ و تشخیص آن]] → [[تفاوت تکواژ آزاد و وابسته]] → [[واژه و معیار تشخیص آن]]
2. [[ریشه و بن واژه]] → [[وند اشتقاقی]] → [[وند تصریفی]] → [[پیشوند در واژه‌سازی]] → [[پسوند در واژه‌سازی]] → [[ترکیب واژه‌ها]] → [[مرز اشتقاق و ترکیب]]
3. [[اسم و معیار تشخیص آن]] → [[اسم عام]] → [[اسم خاص]] → [[اسم ذات]] → [[اسم معنی]] → [[شمار اسم]] → [[مفرد و جمع]] → [[معرفگی اسم]] → [[نکرگی اسم]]
4. [[ضمیر شخصی جدا]] → [[ضمیر شخصی پیوسته]] → [[ضمیر اشاره]] → [[ضمیر پرسشی]] → [[ضمیر مبهم]] → [[ضمیر مشترک]] → [[مرجع ضمیر]] → [[رفع ابهام در ارجاع ضمیر]]
5. [[صفت و معیار تشخیص آن]] → [[جایگاه صفت بیانی]] → [[صفت پیشین]] → [[صفت پسین]] → [[درجهٔ تفضیلی]] → [[درجهٔ عالی]] → [[قید و معیار تشخیص آن]] → [[تفاوت صفت و قید]]
6. [[حرف اضافهٔ ساده]] → [[حرف اضافهٔ مرکب در دستور]] → [[متمم حرف اضافه]] → [[نقش‌نمای را]] → [[کسرهٔ اضافه به‌مثابه نقش‌نما]] → [[حرف ربط هم‌پایه‌ساز]] → [[حرف ربط وابسته‌ساز]]
7. [[گروه اسمی]] → [[هستهٔ گروه اسمی]] → [[وابستهٔ پیشین]] → [[وابستهٔ پسین]] → [[ترتیب وابسته‌های اسم]] → [[گروه فعلی]] → [[هستهٔ گروه فعلی]]
8. [[مصدر]] → [[بن ماضی]] → [[بن مضارع]] → [[شخص فعل]] → [[شمار فعل]] → [[زمان گذشته]] → [[زمان حال]] → [[زمان آینده]] → [[نمود کامل]] → [[نمود استمراری]] → [[وجه اخباری]] → [[وجه التزامی]] → [[وجه امری]] → [[گذر فعل]] → [[معلوم و مجهول]] → [[فعل ساده]] → [[فعل پیشوندی]] → [[فعل مرکب]] → [[فعل عبارتی]] → [[فعل کمکی]] → [[فعل ربطی]]
9. [[نقش دستوری]] → [[نهاد]] → [[گزاره]] → [[مفعول]] → [[متمم]] → [[مسند]] → [[جملهٔ ساده]] → [[جملهٔ مرکب]] → [[جملهٔ پایه]] → [[جملهٔ پیرو]] → [[ترتیب اجزای جمله]] → [[مطابقهٔ نهاد و فعل]] → [[حذف نحوی]] → [[جانشینی نحوی]] → [[ارجاع در متن]] → [[ابهام نحوی]] → [[دستور گفتار]] → [[دستور نوشتار]] → [[تفاوت دستور توصیفی و تجویزی]]

**پایان حوزه:** [[تفاوت دستور توصیفی و تجویزی]] → ورود به حوزهٔ بعدی
