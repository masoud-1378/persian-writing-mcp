# اشتباهات نگارشی پرتکرار

## اشتباهات نگارشی پرتکرار

> شاه‌جدول دربار: پرتکرارترین غلط‌های املا و نگارش فارسی با صورت درست. منبع مبنای انتخاب‌ها: [[سبک‌نامه‌ها و مراجع]] (غلط ننویسیم + مصوبات فرهنگستان). این جدول زنده است؛ هر بار که ویراستاری غلط جدید ببیند، یک سطر اضافه می‌شود.

### گروه ۱: واژه‌هایی که آ/ا دارند

| غلط ✗ | درست ✓ | یادداشت |
|---|---|---|
| خواستگاه | خاستگاه | از «خاستن»؛ «خواهان/خاست» بی‌خ است |
| سر نوشت | سرنوشت | ترکیب وندی؛ چسبیده |
| حاضر جواب | حاضرجواب | چسبیده |
| سپاس گزار | سپاسگزار | چسبیده |
| چشم انداز | چشم‌انداز | نیم‌فاصله (02-پسوندها با نیم‌فاصله) |
| فوق العاده | فوق‌العاده | نیم‌فاصله الزامی |
| قانون گذار | قانونگذار | چسبیده رایج‌تر است |
| متخصص / متخصّص واحد | متخصص | تشدید لازم نیست |
| همانطور | همان‌طور | 03-پیشوندها با نیم‌فاصله |
| همکاران گرانقدرً | همکاران گرامی | بازنویسی تمیزتر |

### گروه ۲: عربی‌وار نگاشته‌های نادرست

| غلط ✗ | درست ✓ | یادداشت |
|---|---|---|
| جزاء عدلی | جزای عدلی | قاعدهٔ کسرهٔ بیانی؛ «جزاء» تنها وقتی که توقف بر آن باشد (05-جزای عدلی و ترکیب‌های قرضی عربی) |
| عمراً نمی‌رود | عمراً نمی‌رود ✓ | درست است؛ «عمرا» بدون تنوین غلط است |
| البته که... حتماً | البته | «البته» مفید کنایی؛ افزودن دوباره زائد |
| مسئواً | مسئولانه | واژه‌سازی ساختگی |
| امریه / مخابره اعطا | صدور حکم مأموریت | ساده‌سازی اداری |

### گروه ۳: ی/ی و ه/ه پایانی

| غلط ✗ | درست ✓ | یادداشت |
|---|---|---|
| فیزیکی/فیزیکى | فیزیکی | همیشه «ی» فارسی نه «ى» عربی |
| خانه ای بزرگ | خانه‌ای بزرگ | نیم‌فاصله + ی (01-ی ناجو) |
| بسازید ؛ سبزید ✔ سبزید | بسازید ✓ | امر جمع: زدید نه زید |
| نگوید | نگوید ✓ | «گوید» سوم شخص با «ی» |

### گروه ۴: ت/ط، ئ/ي، ز/ذ

| غلط ✗ | درست ✓ | یادداشت |
|---|---|---|
| طلبکار | طلبکار ✓ | از «طلب» با ط |
| ماحرم / محروم | محروم | دقت آوایی |
| استفاده زیرا | زیرا ✓ | «زیرا» پیوند دلیل |

### شیوه کم‌کردن غلط در متن وب

1. پس از پایان نگارش، یک دور فقط برای این جدول بخوان (اسکن گروهی).
2. ویرایشگر VS Code یا افزونه‌های املای فارسی نصب کن؛ ولی حرف آخر با چشم انسان است.
3. برگرد به [[چک‌لیست ویرایش نهال‌گشت]] و تیک بخش ۲ را کامل کن.
