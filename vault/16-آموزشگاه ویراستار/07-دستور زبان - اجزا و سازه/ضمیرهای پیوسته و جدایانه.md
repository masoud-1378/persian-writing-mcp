# ضمیرهای پیوسته و جدایانه

## ضمیرهای پیوسته و جدایانه

ضمیر جانشین اسم است تا از تکرار بپرهیزیم. در فارسی دو خانواده دارد: **پیوسته** (می‌چسبد به پایان واژه: ـم، ـت، ـش) و **جدایانه** (خودش می‌ایستد: من، تو، او...). انتخاب نادرست میان این دو، از پرتکرارترین خطاهای متن وب است.

### جدول کامل

| شخص | جدایانه | پیوسته (مالکیت) | پیوسته (مفعول) |
|---|---|---|---|
| مفرد اول | من | کتاب‌**م** | دیدم (در فعل) |
| مفرد دوم | تو | کتاب‌**ت** | |
| مفرد سوم | او / آن | کتاب‌**ش** | دیدم‌**ش** (محاوره) |
| جمع اول | ما | کتاب‌**مان** | |
| جمع دوم | شما | کتاب‌**تان** | |
| جمع سوم | آنان / ایشان | کتاب‌**شان** | |

### قاعده‌های نگارشی

1. **ضمیر پیوسته با نیم‌فاصله یا چسبیده؟** پس از واژهٔ تمام‌شده با صامت، چسبیده می‌آید: «کتابش»؛ پس از مصوت، با نیم‌فاصله: «خانه‌اش»، «لباس‌هایم».
2. **«او» فقط برای جاندار؛ «آن» برای غیرجاندار:** ✓ او مسافر است / ✓ آن هتل خوب است. «آن مسافر» اشاره است، نه ضمیر.
3. **«ایشان» احترامی است:** برای آدم محترم: «ایشان راهنمای تور ما بودند.» برای چیز هرگز: ✗ «ایشان تور کیش بود».
4. **ضمیر جدایانه هرگز نشانهٔ مفعول نمی‌گیرد؛ «را» جدا می‌آید:** ✓ من را ببخشید (رسمی) / ✓ مرا ببخشید (با «م» پیوسته؛ هر دو درست)؛ ✗ «می‌را».

### خطاهای پرتکرار در وب

| ✗ غلط | ✓ درست | توضیح |
|---|---|---|
| تورش شامل ویزاست | تورش شامل ویزاست ✓ (درست است!) | پیوسته پس از صامت چسبیده درست است |
| خانه اش زیباست | خانه‌اش زیباست | پس از مصوت: نیم‌فاصله |
| «شما ها» | شماها / شما | «ها» پس از ضمیر جدایانه با فاصلهٔ کامل |
| کارشون خوب بود | کارشان خوب بود | «شون» محاوره است؛ در متن کتابی «شان» |
| این تصمیم، اورا عوض کرد | این تصمیم او را عوض کرد | «او» و «را» جدا |
| خودم را متعهد کردم به او | خود را متعهد کردم | حشو ضمیر؛ «خودم... به او» یکی را نگه دارید |

### حشو ضمیر: بیماری خاموش متن وب

وقتی نهاد صریح و ضمیر ارجاعی هر دو می‌آیند و دوباره تکرار می‌شوند، متن بوی ترجمه می‌دهد:
✗ «مسافر، چمدانش را برداشت و بعد او تاکسی گرفت و او به هتل رفت.»
✓ «مسافر چمدانش را برداشت، تاکسی گرفت و به هتل رفت.»
قاعده: هر ضمیر باید ارجاع روشن به یک مرجع داشته باشد؛ اگر دو نامزد نزدیک‌اند («هتل» و «مسافر»)، ضمیر را با خودِ اسم جایگزین کنید تا ابهام نماند.

### جمع‌بندی

ضمیر پیوسته می‌چسبد (پس از صامت چسبیده، پس از مصوت نیم‌فاصله)، جدایانه می‌ایستد و «را» را جدا می‌خواهد. «او» برای جاندار، «ایشان» برای محترم، و حشوِ ضمیر را هر بار که متن ترجمه‌وار به نظر رسید، بیرون بکشید.
