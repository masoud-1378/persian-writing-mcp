# نیم‌فاصله، قواعد کلی

## نیم‌فاصله، قواعد کلی

### نیم‌فاصله چیست؟

نیم‌فاصله (Half Space) کاراکتری است با کد **U+200C** در استاند یونیکد. این کاراکتر بی‌عرض (Zero Width Non-Joiner یا ZWNJ) نامیده می‌شود؛ یعنی جایی بین دو بخش از یک واژه قرار می‌گیرد، بدون آنکه فاصلهٔ مرئی ایجاد کند، اما مانع چسبیدن حروف به هم می‌شود.

### تفاوت نیم‌فاصله با فاصلهٔ معمولی و خط تیره

| ویژگی | فاصلهٔ معمولی (Space) | نیم‌فاصله (U+200C) | خط تیره (-) |
|---|---|---|---|
| کد یونیکد | U+0020 | U+200C | U+002D |
| فاصلهٔ مرئی | ✓ بله | ✗ نه (بی‌عرض) | ✓ بله |
| جداکردن واژه‌ها | دو واژهٔ مستقل | دو بخش از یک واژه | پیوستن ظاهری |
| تأثیر بر جستجو | دو نتیجهٔ جدا | یک واژهٔ واحد | یک واژهٔ واحد |

### روش تایپ نیم‌فاصله

| سیستم‌عامل / نرم‌افزار | میانبر |
|---|---|
| ویندوز (صفحه‌کلید فارسی) | `Shift + Space` |
| ویندوز (در Word) | `Ctrl + Shift + 2` |
| مک‌اواس | `Shift + Space` (در صفحه‌کلید فارسی) |
| لینوکس (بیشتر توزیع‌ها) | `Shift + Space` یا `Ctrl + Shift + U` سپس `200C` |
| اندروید (گوگل کیبورد) | نگه‌داشتن کلید فاصله یا از منوی نمادها |
| آیفون (صفحه‌کلید فارسی) | نگه‌داشتن کلید فاصله و انتخاب نیم‌فاصله |

### چرا موتور جستجو نیم‌فاصله را می‌فهمد؟

موتورهای جستجو مانند گوگل متن را در سطح **توکن** (Token) تحلیل می‌کنند. وقتی واژه‌ای با نیم‌فاصله نوشته شود (مثلاً «خانه‌ها»)، موتور جستجو آن را یک واژهٔ واحد می‌فهمد. اما اگر بنویسید «خانه ها» (با فاصلهٔ معمولی)، موتور آن را دو واژهٔ مستقل تلقی می‌کند و نتایج متفاوتی نشان می‌دهد.
این تفاوت برای **سئو** بسیار مهم است: اگر کلیدواژهٔ هدف شما «خانه‌ها» باشد ولی در متن بنویسید «خانه ها»، موتور جستجو ارتباط معنایی را ضعیف‌تر تشخیص می‌دهد.

### قاعدهٔ کلی

> هر جا دو بخش از یک واژه باید از هم جدا بمانند ولی واژه واحد است، نیم‌فاصله بگذارید.

مثال‌های رایج:

| درست ✓ | غلط ✗ | توضیح |
|---|---|---|
| می‌روم | میروم / می روم | پیشوند «می» از فعل جدا می‌شود |
| خانه‌ها | خانه ها / خانهها | نشانهٔ جمع «ها» با نیم‌فاصله |
| بی‌نهایت | بی نهایت / بی‌نهایت | پیشوند «بی» |
| دانش‌آموز | دانش آموز | ترکیب اضافی |

### نکتهٔ مهم

نیم‌فاصله کاراکتری نامرئی است. اگر در ویرایشگر متنی خود آن را نمی‌بینید، نشانهٔ آن است که درست کار می‌کند. برای دیدن آن، نمایش کاراکترهای پنهان (Show Hidden Characters) را فعال کنید.
