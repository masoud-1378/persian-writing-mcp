# فعل مرکب و نیم‌فاصله

## فعل مرکب و نیم‌فاصله

### فعل مرکب چیست؟

فعل مرکب (Compound Verb) فعلی است که از یک جزء اسمی + یک فعل کمکی (مانند کردن، شدن، گرفتن، خوردن، آوردن، دادن) ساخته می‌شود. مثال: «کپی‌برداری کردن»، «مطالعه کردن»، «تماس گرفتن».

### قاعدهٔ طلایی

> در فعل مرکب، **جزء اسمی** با فعل کمکی جداست (با فاصلهٔ کامل)، اما اجزای درونیِ خودِ جزء اسمی با نیم‌فاصله به هم می‌چسبند.

| درست ✓ | غلط ✗ |
|---|---|
| کپی‌برداری کرد | کپی برداری کرد / کپی‌برداری‌کرد |
| عکس‌برداری کردند | عکس برداری کردند |
| برنامه‌ریزی کنیم | برنامه ریزی کنیم |
| مطالعهٔ موردی انجام شد | مطالعه موردی انجام شد |
| تلفن همراه داشتن | تلفن‌همراه‌داشتن |

### تحلیل مثال «کپی‌برداری کردن»

- «کپی» وام‌واژهٔ فرانسوی است + «برداری» مشتق از «برداشتن».
- کل «کپی‌برداری» یک اسم واحد است → با نیم‌فاصله.
- «کردن» فعل کمکی جدا → با فاصلهٔ کامل.

بنویسید:
✓ کپی‌برداری کردن
✗ کپی برداری کردن (سه واژه به نظر می‌رسد)
✗ کپی‌برداری‌کردن (چسباندن فعل کمکی غلط است)

### محل ملاقات

«محل ملاقات» دو جزء مستقل دارد: «محل» (اسم) و «ملاقات» (اسم مصدر عربی). چون هر دو خودشان معنای کامل دارند، **با فاصلهٔ کامل** نوشته می‌شوند:
✓ محل ملاقات
✗ محلملاقات / محل‌ملاقات
اما اگر «ملاقات» نقش فاعلی/صرفی پیدا کند و مسند واقع شود، ساختار تغییر نمی‌کند: «محل ملاقاتِ دو وزیر».

### تلفن همراه داشتن

این عبارت گاهی مسندگونه به کار می‌رود:
✓ او تلفن همراه داشت.
✗ او تلفن‌همراه داشت. (اگر منظور همان فعل مرکب باشد)
البته «تلفن‌همراه» خودش به‌عنوان اسم مرکب جاافتاده است (مترادف موبایل). پس:

- اسم: **تلفن‌همراه** ← با نیم‌فاصله.
- فعل مرکب: «تلفن همراه داشتن» ← اسم + فعل کمکی، با فاصلهٔ کامل.

### قاعدهٔ فعل مرکبِ اسامی

هرگاه فعلی از یک ترکیب اضافی یا وصفی ساخته شود:

1. بین جزء اسمی و فعل کمکی → فاصلهٔ کامل.
2. داخل جزء اسمی اگر چند بخش داشته باشد → نیم‌فاصله.

#### نمونه‌ها

| فعل مرکب | تحلیل |
|---|---|
| مدیریت پروژه کرده | مدیریت (اسم) + پروژه (متمم) + کرده |
| یادگیری ماشین را آغاز کرد | یادگیری (اسم مرکب) + ماشین |
| نظرسنجی انجام دادند | نظرسنجی = نظر+سنجی → نیم‌فاصله |
| رای‌گیری شد | رای+گیری → نیم‌فاصله؛ با «شد» فاصلهٔ کامل |

### سه خطای پرتکرار وب‌نویسان

1. ✗ پیاده سازی کرد ← ✓ پیاده‌سازی کرد
2. ✗ بهینه سازی می شود ← ✓ بهینه‌سازی می‌شود
3. ✗ راه اندازی گردید ← ✓ راه‌اندازی شد («گردید» رسمی اما قدیمی است)

### جمع‌بندی

- اسم مرکب درست‌ساخته ← نیم‌فاصله درون آن.
- اسم + فعل کمکی ← فاصلهٔ کامل.
- «می» پیشوند فعل ← نیم‌فاصله.
- منفی‌سازها (ن/نه) ← پیوسته: نرفت، نتوانست.
